Field Name Definition
RC Command [roll] Raw input from the transmitter roll stick, representing the pilot's desired lateral rotation.
RC Command [pitch] Raw input from the transmitter pitch stick, representing the pilot's desired longitudinal rotation.
RC Command [yaw] Raw input from the transmitter yaw stick, representing the pilot's desired rotation around the vertical axis.
RC Command [collective] Raw input for the vertical thrust/pitch of all main blades simultaneously.
RC Command [throttle] Raw input sent to the motor controller to dictate power output or target RPM.
Setpoint [roll/pitch/yaw] The target rotation rate (deg/s) or angle calculated by the FC after applying rates and expo to RC Commands.
Setpoint [collective] The finalized target for blade pitch after mixing and limits are applied.
Sqrt SP Max [roll/pitch/yaw/collective] A trajectory limit that smooths the setpoint to prevent instantaneous changes that physics cannot follow.
Mixer SR [roll] The output of the mixer for the Roll axis, ready to be sent to the servos.
Mixer SP [pitch] The output of the mixer for the Pitch axis.
Mixer SY [yaw] The output of the mixer for the Yaw axis (usually sent to a tail motor or tail servo).
Mixer SC [collective] The output of the mixer for the Collective axis.
PID P [roll/pitch/yaw] Proportional term: Immediate correction based on the current difference between setpoint and gyro.
PID I [roll/pitch/yaw] Integral term: Corrects for accumulated error over time (e.g., holding against wind or weight imbalance).
PID D [roll/pitch/yaw] Derivative term: Dampens the movement to prevent overshooting the target.
PID Feedforward [roll/pitch/yaw] Provides instant response based purely on stick movement speed, bypassing the error-check delay.
PID Boost [roll/pitch/yaw] Dynamic gain increase during rapid stick inputs to improve "snap" and responsiveness.
PID Offset [roll/pitch/yaw] A constant correction value used to compensate for mechanical biases or trim.
Attitude [roll/pitch/yaw] The calculated orientation of the helicopter in 3D space relative to the horizon.
Unfiltered Gyro [roll/pitch/yaw] Raw angular velocity data from the IMU before any software filtering is applied.
Gyro [roll/pitch/yaw] Cleaned angular velocity data used by the PID controller after filtering out vibrations.
Accel [X, Y, Z] Linear acceleration data used to determine the direction of gravity and for level-mode calculations.
Battery Voltage / Current Real-time voltage and total current draw from the main flight battery.
ESC Voltage / Current / Consumption Telemetry data specific to the ESC, including mAh consumed during the flight.
ESC eRPM The electrical RPM of the motor (must be divided by motor poles to get mechanical RPM).
ESC Throttle / PWM The actual drive signal being sent to the motor by the ESC.
BEC Voltage / Current Status of the Battery Eliminator Circuit powering the electronics and servos.
MCU / ESC Temperature Heat readings for the Flight Controller processor and the Motor Controller.
Gov P Proportional gain: The immediate response to an RPM drop; it increases throttle output proportionally to how far the headspeed has fallen below the target.
Gov I Integral gain: The "persistent" correction that tracks RPM errors over time to ensure the headspeed eventually reaches and holds exactly at the target value.
Gov D Derivative gain: The "damper" that reacts to the speed of RPM change; it helps prevent the motor from over-revving (overshooting) when the load is suddenly removed.
Gov F Feedforward: A predictive boost that adds throttle immediately when it sees a change in Collective or Cyclic sticks, anticipating the load before the RPM even has a chance to drop.
Gov PID sum The total correction output from the governor to the motor.
HS Target / Requested The desired RPM versus what the governor is currently asking the ESC to provide.
Headspeed / Tailspeed The calculated actual RPM of the main and tail rotors.
Motor [1] / [2] The final output signals sent to the Main and Tail ESCs.
Servo [1] / [2] / [3] The final PWM/digital signals sent to the cyclic servos.
Cos Tilt Angle The cosine of the heli's tilt; used to increase collective automatically when banking.
Is Spooled Up / Airborne Boolean flags (On/Off) indicating if the motor is active and if the heli has left the ground.
Is Hands On A flag that triggers when the pilot is actively moving the control sticks.
Flight Mode / State Flags Digital codes representing the current active modes (Angle, Horizon, Acro, etc.).
RX Signal Received / RX Flight Ch. Valid Status of the link between the transmitter and the flight controller.
PID Sum [roll/pitch/yaw] The final output of the PID controller (P+I+D+FF) before mixing.
PID PD Sum [roll/pitch/yaw] The combined value of only the Proportional and Derivative terms, used for vibration analysis.
PID Error [roll/pitch/yaw] The mathematical difference between where you want the heli to be and where the gyro says it is.
